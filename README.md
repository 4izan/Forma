# FORMA — movement studio concept

A responsive Next.js concept site for a fictional movement studio. It includes a filterable sample class schedule, responsive navigation, reduced-motion support, scroll reveals, and a keyboard-friendly booking preview.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev` and open `http://localhost:3000`.

## Editing the content

- Change the sample classes and coach labels in `app/page.tsx`.
- Adjust colors, typography, layouts and motion in `app/globals.css`.
- The booking dialog is a front-end demo only. It does not send or store information; connect a booking provider before taking real reservations.

The studio name, location, schedule and instructor names are illustrative concept content.
